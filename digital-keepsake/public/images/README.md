# Website Image Folders

Place page images in these folders so the website can fetch them from stable public paths:

- `home/` - images used on the home page hero and memory sections.
- `yearbook/` - portrait images used on the yearbook page.
- `messages/` - future images for the messages page or section.
- `wall/` - future images for the batch wall page or section.
- `gallery/` - future gallery images.
- `shared/` - shared fallback or reusable images.

Current expected filenames:

- `home/featured-study.jpg`
- `home/featured-celebration.jpg`
- `yearbook/student-01.jpg`
- `yearbook/student-02.jpg`
- Continue the same pattern through `yearbook/student-30.jpg`

If any image is missing, the app automatically displays `shared/image-placeholder.svg`.
